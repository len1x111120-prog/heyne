1. 서비스

HEYNE는 USB 카드와 컴퓨터에서 실행되는 도우미 프로그램으로 이루어진 AI 비서입니다. AI 답변은 사용자가 선택한 외부 AI 서비스가 만들며, 사용자는 해당 서비스의 약관과 요금을 따릅니다.

2. 사용자의 책임

  • AI 서비스 API 키와 카드 PIN은 사용자가 관리합니다.
  • HEYNE는 사용자가 허용한 범위에서 컴퓨터의 명령을 실행하거나 파일을 만들 수 있습니다. 실행을 허용하기 전에 내용을 확인해 주세요.
  • AI 답변은 틀릴 수 있습니다. 중요한 결정에는 반드시 직접 확인해 주세요.
  • 법을 어기거나 다른 사람에게 해가 되는 용도로 쓰지 마세요.

3. 구글 드라이브

드라이브 백업은 선택 기능이며, 구글 서비스 이용에는 구글의 약관이 적용됩니다. 언제든 연결을 해제할 수 있습니다.

4. 보증의 제한

HEYNE는 “있는 그대로” 제공됩니다. 법이 허용하는 범위에서, 제작자는 서비스의 중단, 데이터 손실, AI 답변이나 사용자가 허용한 명령 실행으로 생긴 손해에 대해 책임지지 않습니다. 중요한 대화는 드라이브 백업을 켜 두는 것을 권합니다.

5. 변경과 문의

약관이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 문의: GitHub 문의 페이지.
